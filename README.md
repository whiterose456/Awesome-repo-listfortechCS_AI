## 🎯 How to Use This Hub

Daily (15 min):
- Hacker News front page
- TLDR newsletter
- GitHub Trending

Weekly (1 hour):
- Import AI or The Batch
- ArXiv cs.AI recent papers (skim titles)
- One long-form piece from MIT Tech Review or Wired

Monthly (deep dive):
- Read 2-3 papers from Papers With Code
- Listen to a Latent Space or Changelog podcast episode
- Review Stratechery or Benedict Evans for strategic context
